# Эмулятор языка оболочки ОС

## 1. Общее описание
Консольное приложение на Rust, имитирующее интерфейс командной строки UNIX.

## 2. Описание всех функций и настроек
- `ls` — выводит имя команды-заглушки и переданные аргументы.
- `cd` — выводит имя команды-заглушки и переданные аргументы.
- `exit` — завершает работу эмулятора.

## 3. Описание команд для сборки проекта и запуска тестов
Сборка и запуск проекта осуществляются через `Makefile`:
- `make build` — сборка проекта.
- `make run` — запуск эмулятора в интерактивном режиме.

## 4. Примеры использования
```text
vfs> ls -la "my documents"
[Заглушка] Вызвана команда 'ls'
Аргументы: ["-la", "my documents"]
```
